# 💻 Portfolio Yeray Jurado

Portfolio personal de **Yeray Jurado**, desarrollador Full Stack en formación, creado para presentar mi perfil profesional, formación, experiencia, stack técnico y proyectos.

## 🚀 Vista general

Este portfolio está desarrollado como una web estática con un diseño **dark**, minimalista y responsive.
El objetivo es mostrar de forma clara mi evolución como desarrollador web y las tecnologías que estoy aprendiendo y utilizando durante mi formación en **DAW**.

## 🛠️ Tecnologías utilizadas

* 🌐 HTML5
* 🎨 CSS3
* ⚡ JavaScript
* ☕ Java
* 🍃 Spring
* 🅰️ Angular
* 🗄️ SQL
* 🐬 MySQL
* 🌿 Git

## 📌 Secciones del portfolio

* 🏠 **Inicio:** presentación principal, perfil y llamadas a la acción.
* 🧰 **Stack técnico:** tecnologías organizadas por frontend, backend, bases de datos y herramientas.
* 📂 **Proyectos:** zona preparada para mostrar proyectos personales, académicos o profesionales.
* 👨‍💻 **Sobre mí:** presentación personal y objetivos como desarrollador.
* 🎓 **Formación y experiencia:** recorrido académico y prácticas profesionales.
* 📬 **Contacto:** email y acceso al currículum.
